# happybird05.github.io

CV, 논문 리뷰, 개인 연구 기록용 정적 블로그 템플릿입니다.

## 파일 구성
- `index.html`: 메인 템플릿 (섹션: CV / 논문 리뷰 / 개인 연구 / 연락처)
- `styles.css`: 전체 스타일 (반응형 포함)

## 빠른 수정 포인트
- 이름/소속/이메일: `index.html`의 `About` 카드
- CV 내용: `#cv` 섹션
- 논문 리뷰 카드: `#paper-reviews` 섹션의 `paper-card`
- 개인 연구 로그: `#research` 섹션의 `research-item`
- CV PDF 링크: `PDF CV 다운로드` 앵커의 `href`

## 로컬 확인
브라우저에서 `index.html`을 열면 바로 확인할 수 있습니다.
